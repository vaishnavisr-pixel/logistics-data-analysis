# logistics-data-analysis
Week 1 logistics data analysis project focusing on strategic planning, KPIs, and Python-based data analysis.

Project:

- Strategic Planning and Data Exploration in Logistics

Objective:

- Plan a Python-based analysis of inventory and delivery performance using logistics KPIs.

Proposed KPIs:

- On-Time Delivery Rate

- Average Delivery Time

- Inventory Turnover

- Stockout Rate

- Transportation Cost per Order

- Planned Methods

- Data cleaning and exploratory data analysis

- Regression for delivery-time/cost prediction

- Clustering for route/product/customer segmentation

- Optimization for resource or route allocation

Files:

- logistics_analysis.py – starter Python analysis

- Week_1_Logistics_Data_Analysis_Report_Vaishnavi_SR.docx – Week 1 report

Note:

- The Week 1 report is a strategic plan. It does not claim results before a dataset is collected and analyzed.
